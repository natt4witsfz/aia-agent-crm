# AIA Agent CRM — ระบบจัดการลูกค้าประกันสำหรับตัวแทน

WebApp สำหรับตัวแทนประกัน: บันทึกข้อมูลลูกค้า, แผนที่ลูกค้า, การแจ้งเตือน, กรมธรรม์, เคลม, เครื่องมือการเงิน และผู้ช่วย AI

## วิธีเริ่มใช้งาน

1. เปิดโฟลเดอร์นี้ใน terminal แล้วรัน:
   ```powershell
   python -m http.server 4180
   ```
2. เปิดเบราว์เซอร์ไปที่ http://localhost:4180
   (ต้องมีอินเทอร์เน็ต — แผนที่ OpenStreetMap และไลบรารีโหลดจาก CDN)

> เปิดไฟล์ `index.html` ตรง ๆ ก็ใช้ได้ แต่แนะนำผ่าน http server

## ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 👥 ลูกค้า | เพิ่ม/แก้ไข/ค้นหา/กรองตามสถานะ พร้อมสี: เขียว=ปัจจุบัน, ม่วง=VIP, ส้ม=ผู้มุ่งหวัง, เทา=ขาดต่อ |
| 🗺️ แผนที่ | OpenStreetMap — หมุดสีตามสถานะ ไอคอนตามประเภทประกัน คลิกหมุดดูรายละเอียด, เปิด "โหมดปักหมุด" แล้วคลิกแผนที่เพื่อเพิ่มลูกค้าที่ตำแหน่งนั้น |
| 🔔 แจ้งเตือน | ต่ออายุ/วันเกิด/ติดตาม — สร้างอัตโนมัติ 14 วันก่อนวันครบกำหนดเมื่อเพิ่มกรมธรรม์ |
| 📄 กรมธรรม์ | เลขกรมธรรม์ แบบประกัน เบี้ย ทุน วันครบกำหนด ผูกกับลูกค้า |
| 🏥 เคลม | ฐานข้อมูลเคลม: วันที่ ประเภท จำนวนเงิน สถานะ (รอ/อนุมัติ/จ่ายแล้ว/ปฏิเสธ) |
| 🧮 การเงิน | ภาษีเงินได้บุคคลธรรมดา (อัตราไทย + ลดหย่อนเบี้ยประกัน), IRR จากกระแสเงินสด, คำนวณเงินออมทบต้น |
| 🤖 AI | ผู้ช่วย Claude — สรุปลูกค้า/กรมธรรม์, หา renewal ที่ใกล้ถึง, ร่างข้อความ LINE, วิเคราะห์เคลม |
| 🌐 ภาษา | ไทยเป็นค่าเริ่มต้น สลับ EN ได้ที่มุมล่างซ้าย |

## ตั้งค่า Supabase (ฐานข้อมูลคลาวด์ ฟรี)

1. สมัครที่ https://supabase.com (ฟรี) → New Project
2. ไปที่ SQL Editor → วางเนื้อหาไฟล์ `supabase-schema.sql` → Run
3. ไปที่ Project Settings → API → คัดลอก **Project URL** และ **anon public key**
4. ในแอป: ตั้งค่า → Supabase → วาง URL + key → "บันทึกและเชื่อมต่อ"

ข้อมูลที่มีอยู่ในเครื่องจะถูก sync ขึ้นคลาวด์อัตโนมัติตอนเชื่อมต่อครั้งแรก
ก่อนเชื่อมต่อ ข้อมูลเก็บใน browser (localStorage) — ใช้ปุ่มสำรองข้อมูลเป็นประจำ

## ตั้งค่า Claude AI

1. สร้าง API key ที่ https://platform.claude.com (เติมเครดิตขั้นต่ำ ~$5)
2. ตั้งค่า → Claude AI → วาง key → เลือกโมเดล (แนะนำ Sonnet; Haiku ถูกสุด)
3. ค่าใช้จ่ายโดยประมาณ: ~$1–6/เดือน สำหรับการใช้งานปกติ

⚠️ Key เก็บใน browser ของคุณเท่านั้น อย่าแชร์เครื่อง/ไฟล์ backup ที่มี key ให้ผู้อื่น

## โครงสร้างไฟล์

- `index.html` — layout ทั้งหมด
- `styles.css` — สไตล์
- `i18n.js` — ระบบสองภาษา TH/EN
- `store.js` — ชั้นข้อมูล: Supabase + localStorage fallback
- `map.js` — แผนที่ Leaflet/OSM
- `finance.js` — ภาษี/IRR/การลงทุน
- `ai.js` — เชื่อมต่อ Claude API
- `app.js` — UI หลัก
- `supabase-schema.sql` — สคีมาฐานข้อมูล
